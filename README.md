# Plotloom

AI short drama creation engine — a skill-first production workflow for turning story sparks into short-drama artifacts.

> Working name history: early notes used `dramaclaw`; the product/repo name is now **Plotloom**.

## Current contents

This repository currently contains the early research and handoff documents that shaped Plotloom's direction.

```text
docs/
  handoffs/        # prior MT/Nova handoff context
  research/        # route decisions and market/tooling research
  source-reading/  # GitHub prior-art reading notes
```

## Direction

Plotloom is intended to be a **skill-first** short-drama production pack, not a heavy platform first:

```text
story / episode input
  -> assets / characters / setting
  -> beat sheet / storyboard
  -> image prompts
  -> video prompts
  -> generation execution
  -> assembly / subtitles / cover / manifest
  -> review / rerun loop
```
