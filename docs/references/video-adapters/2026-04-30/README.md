# Video adapter source snapshots

Downloaded by Nova on 2026-04-30 for implementing Plotloom video adapters.

Contents:

- `dreamina-cli/`: local `dreamina * --help` outputs for text2video, image2video, multiframe2video, multimodal2video, query_result.
- `fal-happyhorse/`: fal docs and HappyHorse API page snapshots.
- `volcengine-seedance/`: VolcEngine Seedance / video generation API page snapshots.

Notes:

- Some provider API pages are saved as raw HTML because the docs are rendered by web apps.
- Do not treat snapshots as always-current; verify against live provider docs before implementing production behavior.
- These files intentionally contain no API keys or account credentials.
