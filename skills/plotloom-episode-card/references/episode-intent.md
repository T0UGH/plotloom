# Episode Intent Reference

## Short-Drama Episode Anatomy
- **0-3s hook:** visible pressure, humiliation, threat, or mystery.
- **Setup:** who wants what in this episode.
- **Escalation:** power imbalance becomes sharper.
- **Reversal/reveal:** identity, leverage, private phrase, evidence, or unexpected ally changes the scene.
- **Ending hook:** final frame creates the next clip/episode question.

## Strong Hooks
- A character is publicly underestimated.
- A prop or phrase reveals hidden identity.
- A villain makes a visible mistake.
- A quiet character refuses the expected status role.

## Weak Hooks
- Pure exposition.
- Long backstory voiceover before any visible conflict.
- A generic argument with no series-specific pressure.

## Episode Card Is Not a Script
The episode card anchors intent. It should not become mandatory `script.md`, `storyboard.md`, or director brief. If the user needs those artifacts, ask before expanding scope.

## Preserve the Series Engine
Every episode should exercise the recurring conflict engine while adding one concrete change: new evidence, new ally/enemy, new cost, or new public reversal.
